## Task 3: Каталог, поиск по названию, локальная библиотека

**Description:** Произведение и обзор — отдельные типы. Локальный каталог с альтернативными названиями. Транслитерация кириллицы в латиницу для совпадения запроса. Публикации, свои произведения, XP, сохранения, подписки и реакции читаются из `localStorage` через проверку формы. Свой статус нельзя пометить как подтверждённый администратором.

**Acceptance criteria:**

- [ ] Запрос «атака» и «ataka» находит «Атака титанов», «shingeki» находит альтернативное название
- [ ] Пустой и слишком длинный запрос не совпадает со всем каталогом по ошибке (пустой запрос — отдельное правило «показать список»)
- [ ] Битая или огромная запись в хранилище не роняет приложение
- [ ] У произведения из хранилища `statusSource` всегда `user`

**Verification:**

- [ ] `npm test`
- [ ] `npm run build`

**Dependencies:** нет (можно сразу после Task 1, от панели не зависит)

Нижняя панель: все типы, статус, сортировка, сброс и применение. В «Для тебя» чередуются редакционная и компактная карточки. У автора вертикальная полоса репутации. Порция по `feedPageSize` (10) и догрузка по скроллу. «Подписки» пустые, пока ни на кого не подписан.

- [ ] Пустые фильтры и пустые подписки — отдельные пустые состояния, не пустой экран

## Task 7: Поиск

**Description:** Один поиск, три режима: произведения, обзоры, авторы. Произведения — компактные строки. Обзоры — карточки с фрагментом. Авторы — аватар, репутация, предпочтительные категории. Пустой запрос показывает каталог, не ошибку.

**Acceptance criteria:**

- [ ] Смена режима не теряет строку запроса
- [ ] Нет результатов — отдельное состояние
- [ ] Строка произведения ведёт на карточку, обзор — на обзор, автор — на профиль

**Verification:**

- [ ] `npm test` (транслитерация) и `npm run build`

## Task 10: Профиль и достижения

**Description:** Свой профиль берёт имя из сессии. Чужой — из каталога по `/users/:id`. Обложка, аватар, подписка (не на себе), вкладки «Обзоры», «Оценки», «Достижения». Обзоры — сетка обложек и переключатель на список. Отпечаток — доли категорий. Достижения считаются по опубликованным типам. Рамка есть только когда закрыты четыре группы. Пустая своя коллекция — пустое состояние со ссылкой создать обзор, не чужие цифры.

**Acceptance criteria:**

- [ ] Свой профиль не показывает чужую репутацию и чужой ранг
- [ ] Аватар есть до первого достижения
- [ ] Сетка ведёт на произведение, список — на обзор
- [ ] `/achievements` показывает ту же доску, не второй заглушечный текст

**Verification:**
