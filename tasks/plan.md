# План: интерфейс ReviewHub

## Обзор

Собрать тёмный интерфейс Mini App по концепту: контент важнее хрома, два формата карточек, произведение отдельно от обзора, мастер из трёх шагов, профиль как коллекция. Семь экранов MVP плюс статичный список уведомлений, потому что нижняя панель из пяти кнопок иначе ведёт в пустоту.

Бэкенд не трогаем. Каталог локальный. Публикация сохраняется на устройстве и не выдаётся за ответ API.

## Что уже есть

React 19, Vite, FSD (`app → pages → widgets → features → entities → shared`). Роуты: лента, поиск, создание, профиль, достижения, настройки, обзор. Вход через Telegram закрывает приложение до сессии. Лента — две мок-карточки и синяя палитра. Страницы обзора, поиска, создания и достижений — заглушки. Tiptap, Radix Dialog и Zustand уже подключены.

## Решения

- Палитра и шрифт из концепта: фон `#101413`, карточки `#1B2220`, акцент `#A4C8AC`, текст `#F2F4F0`, вторичный `#929F99`, границы `#303B35`, золото `#D3AC76`. Manrope с системным запасным шрифтом. Скругления 14–20px. Зелёный только на активном состоянии, кнопках и прогрессе. Текст на зелёной кнопке тёмный: светлый текст на `#A4C8AC` не проходит контраст.
- Новые библиотеки не добавляем. Редактор — уже стоящий Tiptap (StarterKit, изображение по `https`, спойлер, таймкод). Нижняя панель фильтров — тот же `Modal`.
- Произведение и обзор — разные типы. Статус выпуска хранится у произведения вместе с источником: `admin`, `api`, `user`. На карточке и странице произведения неподтверждённый источник подписан. Лайки статус не определяют.
- Обложка — градиент из палитры и буква названия. Чужие постеры не встраиваем.
- Аватар-буква доступен сразу. «Исследователь» (обзор в каждой из четырёх групп: манга, аниме, сериалы, фильмы) открывает рамку профиля, не аватар.
- Опыт (XP) копится локально за публикацию и не уменьшается. Репутация каталожных авторов — отдельное число. Локальная публикация репутацию не повышает.
- «Для тебя» показывает каталог без персонального ранга. Ранг появится вместе с сигналами интересов.
- Поиск: произведения, обзоры, авторы. Совпадение по названию, альтернативным названиям и транслитерации кириллицы. Без нечёткого поиска.
- Сравнение взглядов на странице произведения — доли оценок «за / смешанно / против», не разбор аргументов.
- Культурный отпечаток — доли категорий и полоса, не отдельная графика.
- Комментарии, набранные на странице обзора, живут до перезагрузки. Сохранённые, подписки, лайки и черновик пишутся в `localStorage`.
- Навигация скрыта на странице обзора и в мастере создания. Учитывается `safe-area-inset-bottom`.
- Колонка Mini App не шире 480px.

## Вне этой итерации

Серверная лента и антинакрутка, поиск людей со схожим вкусом, разбор аргументов рецензий, анимированные рамки, загрузка файлов, живые уведомления, связи адаптаций сложнее списка `relatedIds`.

## Порядок

Фундамент (токены, навигация, контракт каталога) → чтение (лента, обзор, произведение) → действие (поиск, мастер, профиль, экран входа). Задачи и критерии — в [tasks/todo.md](./todo.md).

## Риски

| Риск | Влияние | Что делаем |
| --- | --- | --- |
| Внутренние экраны за `AuthGate` | Нельзя снять их в браузере без сессии Telegram | Экран входа проверяем визуально. Остальное — сборка, тесты и обход сценария кодом |
| Порча `localStorage` | Битый JSON или поддельный статус «подтверждено» | Разбор в try/catch, лимит размера, отбрасывание кривых записей. У своего произведения источник всегда `user` |
| HTML редактора | XSS, если вставить его в DOM как есть | В страницу попадает только разбор схемой Tiptap. Ссылки и `javascript:` в редакторе выключены. Картинки — только `https` |
| Google Fonts недоступен | Другой вид букв | Остаётся системный шрифт, вёрстка не зависит от метрик Manrope |
